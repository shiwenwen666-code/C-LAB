## 命名方式

每个文件夹内的主封面统一命名为 `cover`，保留原始扩展名即可，例如：

- `cover.mp4`
- `cover.webm`
- `cover.gif`
- `cover.jpg`
- `cover.jpeg`
- `cover.png`
- `cover.webp`

每个 Case 先放一个希望使用的主封面。视频建议静音、约 10 秒，并适合循环播放。
