# C-LAB Portfolio

施文文（CYAN LAB）的个人作品集网站，聚焦国际商业视觉、AIGC 工作流与品牌内容设计。

## 在线访问

[https://shiwenwen666-code.github.io/C-LAB/](https://shiwenwen666-code.github.io/C-LAB/)

## 主要内容

- 五个精选 Work Case，包含视频、GIF、长图与项目说明
- AIGC 与视觉设计实验项目
- 奖项与证书展示
- 中英文切换与深浅色主题
- 响应式桌面及移动端体验
- 联系方式与个人简介

## 本地运行

需要 Node.js 20+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 技术栈

React、TypeScript、Vite、Framer Motion、React Router。

## 部署

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。部署配置位于 `.github/workflows/deploy-pages.yml`。
